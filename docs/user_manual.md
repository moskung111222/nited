# คู่มือการใช้งานระบบนิเทศภายใน (e-Supervisor User Manual)
**สำหรับโรงเรียนนราศึกษาธิการ**

---

## 👨‍🏫 1. คู่มือสำหรับ "ครูผู้รับการนิเทศ"

บทบาทของครูคือการเข้าไป **จองวันนิเทศ** และ **ส่งไฟล์งาน (แผนการสอน)** เพื่อให้ผู้นิเทศตรวจประเมิน

### 1.1 การเข้าสู่ระบบ (Login)
1. เข้าไปที่หน้าแรกของเว็บไซต์
2. คลิกปุ่ม **"เข้าสู่ระบบ"** ที่มุมขวาบน
3. กรอก Username และ Password (ติดต่อ Admin เพื่อขอรับข้อมูล)
4. ตอบคำถามคณิตศาสตร์ (ยืนยันตัวตน) แล้วกดปุ่ม "เข้าสู่ระบบ"

### 1.2 การจองวันนิเทศ
1. หลังล็อกอิน ให้คลิกเมนู **"จองวันนิเทศ" (Booking)**
2. คลิกปุ่ม **"+ จองวันนิเทศ"** จะปรากฏฟอร์มให้กรอกข้อมูล
3. ระบุรายละเอียดให้ครบถ้วน:
   * วันที่ และ เวลา ที่ต้องการ
   * คาบเรียน (เช่น คาบ 1, คาบ 2)
   * ชื่อวิชา และ รหัสวิชา
   * ระดับชั้น และ ห้องเรียน (เช่น ม.1/1)
4. ตรวจสอบข้อมูลแล้วกด **"บันทึกข้อมูล"**
5. สถานะการจองจะเป็น **"รอดำเนินการ"** (รอผู้นิเทศยืนยัน)

### 1.3 การส่งไฟล์งาน (แผนการสอน/สื่อการสอน)
1. ไปที่เมนู **"ส่งงาน" (Files)**
2. คลิกปุ่ม **"+ ส่งไฟล์งาน"**
3. เลือก "ประเภทไฟล์" (เช่น แผนการสอน, สื่อการสอน, บันทึกหลังสอน)
4. เลือก "รายการจอง" ที่ต้องการส่งไฟล์แนบ
5. เลือกไฟล์จากคอมพิวเตอร์ (รองรับ PDF, Word, รูปภาพ)
6. กด **"อัปโหลดไฟล์"** (ระบบจะอัปโหลดไปยัง Google Drive อัตโนมัติ)
7. สถานะไฟล์จะเป็น **"รอตรวจสอบ"**

### 1.4 การดูผลการประเมิน
* ครูสามารถกลับมาดูผลการนิเทศได้ที่หน้า **"หน้าหลัก"** หรือในตารางการจองเมื่อสถานะเปลี่ยนเป็น **"นิเทศแล้ว"**

---

## 🕵️‍♂️ 2. คู่มือสำหรับ "ผู้นิเทศ" (Supervisor)

บทบาทของผู้นิเทศคือการ **ตรวจไฟล์งาน** และ **บันทึกผลการนิเทศ** 

### 2.1 การตรวจสอบตารางการจองและไฟล์งาน
1. เข้าสู่ระบบด้วยบัญชีระดับผู้นิเทศ
2. ระบบจะแสดงเมนู **"ประเมินผล" (Evaluation)** เพิ่มขึ้นมา ให้คลิกเข้าไป
3. ในหน้านี้จะแสดงคิวที่ครูจองเข้ามา และสามารถคลิก **"ดูไฟล์งาน"** ของครูแต่ละท่านได้

### 2.2 การประเมินและการนิเทศ
1. ในหน้า **"ประเมินผล"** ให้เลือกรายการจองที่ต้องการประเมิน
2. กรอกฟอร์มการประเมิน:
   * **จุดเด่น:** สิ่งที่ทำได้ดี
   * **จุดที่ควรพัฒนา:** สิ่งที่ต้องปรับปรุง
   * **ข้อเสนอแนะ:** แนวทางในการพัฒนา
   * **ให้คะแนน:** ตามเกณฑ์ของโรงเรียน
3. กดบันทึก ระบบจะคำนวณ **"ระดับคุณภาพ"** อัตโนมัติ (เช่น ดีมาก, ดี, พอใช้) และสถานะการจองของครูจะเปลี่ยนเป็น **"นิเทศแล้ว"**

---

## ⚙️ 3. คู่มือสำหรับ "ผู้ดูแลระบบ" (Admin)

ผู้ดูแลระบบมีสิทธิ์เข้าถึงทุกส่วน และจัดการผู้ใช้งานได้

### 3.1 การจัดการผู้ใช้งาน (Users)
1. เข้าสู่ระบบด้วยบัญชี `admin`
2. ไปที่เมนู **"ผู้ดูแลระบบ" (Admin)**
3. สามารถ **เพิ่ม**, **แก้ไข**, หรือ **ปิดการใช้งาน (Deactivate)** บัญชีของครูหรือผู้นิเทศได้
4. สามารถเปลี่ยนรหัสผ่าน (Reset Password) ให้ผู้ใช้ที่ลืมรหัสผ่านได้

### 3.2 การติดตามสถิติและรายงาน
1. ไปที่เมนู **"รายงาน" (Reports)** หรือ **"หน้าหลัก"**
2. ระบบจะแสดง Dashboard สรุปจำนวนการจอง, กราฟระดับคุณภาพ, และสถิติแยกตามกลุ่มสาระการเรียนรู้
3. สามารถ Export ข้อมูลไปทำรายงานสรุปประจำเดือน/ประจำปีได้ (ผ่าน Google Sheets)

---

## ❓ 4. การแก้ไขปัญหาเบื้องต้น (FAQ / Troubleshooting)
* **ลืมรหัสผ่าน:** ให้ติดต่อผู้ดูแลระบบ (Admin) เพื่อทำการ Reset รหัสผ่านในหน้า Admin
* **อัปโหลดไฟล์ไม่ผ่าน:** ตรวจสอบขนาดไฟล์และประเภทไฟล์ (ระบบรองรับขนาดที่ Google Drive อนุญาต)
* **หน้าเว็บไม่แสดงข้อมูลล่าสุด:** ให้ลอง Refresh หน้าจอ (กด F5) หรือล้าง Cache ในเบราว์เซอร์
